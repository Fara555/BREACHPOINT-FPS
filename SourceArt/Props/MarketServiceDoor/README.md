# Market service door

Closed utility bulkhead replacing the central open rack and all five supply cassettes at world z40.5. Editable native source: MarketServiceDoor.blend; builder: build_door.py; Unity FBX and reusable PF_MarketServiceDoor prefab: Assets/Project/Art/Props/MarketServiceDoor. Real scale, 5112 triangles, four shared HDRP wall finishes. The door deliberately reuses the accepted MarketWallLining material library without changing its assets.

Model construction: continuous annular folded surround with clipped/radiused corners, recessed closed leaf, continuous dark seal backing, replaceable enamel facing, lower impact shoe, captive hinges, latch mount/rounded handle, narrow identity inlay and threshold plate. After user feedback the placement moved 650mm into the wall, to x=-17.45. The frame stands 24mm proud of the lining; the enamel face is 3mm behind it. MarketWallLining now has an actual aperture and header in this location. This remains a closed door, with no opening animation, interaction, new room or traversable connection.

The former rack collider is fitted to the recessed door: position(-17.50,1.47,40.5), size(.40,2.91,2.3). This removes the old invisible projection into the room. A centerline spherecast verifies contact at x=-17.30. Actors, routes, other collision and baked navigation bytes remain unchanged; the existing bake conservatively avoids the formerly occupied space and is not rebaked for a closed door. Before/after fingerprints are stored alongside this source as GameplayBeforeRecess.sha256.txt and GameplayAfterRecess.sha256.txt; the pre-recess scene is archived in Logs/MarketServiceDoor. Historical baselines are not overwritten: MatchesGameplay normalizes only this explicitly revised collider's position/size, while validating its new values and comparing every other fingerprint input exactly. Default GameplayFingerprint still reports the actual scene.

Commands in the existing Editor bridge: market-service-door-create / market-service-door-validate / market-service-door-capture. Create saves root19 and its linked prefab; all setup is complete. Capture reviews front, oblique and handle views in Logs/MarketServiceDoor.

Canonical room assets are retained byte-for-byte. Owned Integration mesh index buffers omit 8076 triangles wholly inside the central rack envelope (including shelves, upright/back, cassette bodies/lids/grips/latches/pivots and shelf/header strips). Visible source mesh triangles are audited against the same envelope after replacement; no fragments may remain. Other attributes and geometry are preserved. The old internal-facing material remains archived by the earlier wall pass. Packet and wall filters are rebuilt first and composed into the door filter. Room RefreshSurfaces reapplies this final filter after those earlier passes; reauthoring the packets/walls also retains the replacement. The integration assets are scene migration data, not dependencies of the reusable door prefab.

Validation covers link/material/bounds, full visible rack removal, no new runtime components/lights/colliders, the explicit collision revision and unchanged other gameplay/nav inputs, canonical room/furniture art bytes and all prior wall/desk/fan reference checks. The owned wall lining is revised to fit the recessed frame. No combat route tests, navigation bake, new package or project setting is involved. The model is visually inspected in actual HDRP; no performance/build claim is made.

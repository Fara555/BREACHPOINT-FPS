# Sealed supply pack

Reusable standalone field-ration pouch. This replaces the ambiguous rectangular packets and orange bars formerly embedded in the market room model.

- Editable source: SealedSupplyPack.blend, generated by build_supply_pack.py.
- Closed manifold foil body with a softly filled center, compressed flange, small seam folds and a tear notch. Bottom-center origin;0.38x0.26m footprint, approximately0.072m height.3596 triangles, one material slot.
- bake_print.ps1 authors the top/bottom packaging print and label mask using the project's existing Orbitron font and built-in Windows drawing APIs. The exported Unity asset requires no font reference or package.
- Unity asset: Assets/Project/Art/Props/SealedSupplyPack/PF_SealedSupplyPack.prefab, with its own FBX, HDRP Lit material and1024x2048 base-color/mask/normal textures. Metallic foil and matte printing use the same mask-packed material. No collider, light, runtime component, POM or displacement is added.

Authoring commands: supply-pack-create, supply-pack-validate, supply-pack-capture. Creation remaps the model, saves a standalone prefab and places two linked instances inside the existing tray. Close-up and placement views are in Logs/SealedSupplyPack.

Legacy integration: canonical accepted room FBX/material files are retained unchanged. Editor-only filtered mesh index buffers under Integration omit only272 triangles wholly inside the two old packet envelopes. All other vertex data and materials are retained. The scene's affected MeshFilters use these filtered meshes. BattlefieldMarketRoom.RefreshSurfaces regenerates the filter from the current canonical mesh whenever room art is reimported, so unrelated future edits do not become frozen. The old packet primitive generation was removed from build_market.py; when a later canonical rebuild no longer contains them, the filter restores the canonical mesh reference automatically.

Integration meshes are level migration data, not dependencies of the reusable prop prefab. Exporting the prefab with its dependencies includes only the prop model/material/textures. Source manifold/scale report: SupplyPackReport.json. Unity validation checks prefab links, ownership, HDRP maps/color spaces/filtering, tray fit and exact gameplay/nav fingerprint. No combat-route test or navigation bake is required for this art replacement.

Project policy is now in AGENTS.md: future small independent props must be individually authored, reusable assets with a close-up review before placement. Avoid generic placeholder primitives embedded into the room mesh.

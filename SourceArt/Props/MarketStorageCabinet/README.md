User specifically rejected the pictured plain storage cabinet. A dedicated reusable PF_MarketStorageCabinet now lives under Assets/Project/Art/Props/MarketStorageCabinet and root21.

Native source: MarketStorageCabinet.blend, generated by build_cabinet.py. Six export finish groups, source21190tri/Unity21170tri, within30000tri budget. Real-scale bottom-center origin, front faces +X. Construction includes a continuous folded shell/return, rear closure, overhanging crown, recessed toe pedestal, two pressed closed doors and individual seals, six machined hinges/barrels/washers, rounded one-piece tubular pulls with captive mounts/screw slots, key cylinder and a printed identification inset. The plate uses explicit outward normals/UVs, separated2mm from its backing. No opening mechanic, runtime script, collider or light is added.

Materials: six owned HDRP Lit finishes. Separate coat and door-paint base/mask/normal sets have restrained scuffs, broken edge chips, variable roughness and fine surface relief. Rubber remains nonmetallic; brushed hardware has a distinct metal/smoothness response. Door paint uses a2048px two-half atlas (different wear on each door); body1024px; hardware/rubber/accent512px. The1024x344 identification print is authored by bake_label.ps1 using built-in Windows drawing and the existing Orbitron font. All maps are mipmapped, trilinear/aniso8 with correct sRGB/data spaces, normals and geometric specular AA. Native sources/UV1 meter mapping are retained; no new package or shader.

Authoring: run build_cabinet.py in Blender and bake_label.ps1 in PowerShell, then market-cabinet-create in the existing Editor bridge. MarketCabinetMaterials.cs bakes/maps owned PBR assets; create saves the prefab/scene and captures context/hardware/plate views. market-cabinet-validate / market-cabinet-capture are available separately. No manual Inspector configuration is needed.

Legacy integration:1456 south-cabinet triangle indices are omitted in owned Integration mesh copies. Other vertex data/materials/triangles and all canonical files stay unchanged. This preserves prior replacements and regenerates from their latest source on subsequent reimports. MarketServiceDoorAuthoring.ApplyRackRemoval calls this replacement last. Integration assets are scene migration data, not prefab dependencies. Future canonical source removal of old furniture restores its original source mesh when no matching triangles remain.

Current user direction (2026-11-15): add a small amount of daily-use clutter and an active object such as a fan to make the room feel occupied. This explicitly supersedes the previous pause on additions for the daily-use pass only. Keep new props on the counters and preserve the accepted room/floor/devices; see Life/README.md.

Run `build_market.py` with Blender in background mode to export the two owned FBX files into `Assets/Project/Art/Environment/ServiceQuarter/MarketRoom/Models`.

The script opens the accepted InteriorFinish source without saving over it. It filters only the old west workshop cladding into `InteriorWithoutWorkshop.fbx`, then builds `MarketRoom.fbx` and the editable `MarketRoom.blend`. Existing environment and QuietFloor source files remain unchanged.

The market has north and south doorways (2.8 m nominal width, 3.2 m nominal height) and an east serving window (3 m nominal width). The window has a solid 1.15 m breast wall and a 1.27 m sill top, with an open aperture and no glass. Counters sit against the east wall and storage against the west wall. The central aisle stays open. New floor sheets continue the existing 40 mm joints and HDRP material; the existing full-room joint bed remains the only backing surface.

Detail pass one builds the deep window frame, raised security shutter housing, folded serving shelf, lower removable panels, broad facade edge rails and counter service doors. It reuses accepted HDRP materials and does not alter their textures. Later surface/prop passes can be reviewed separately.

In Unity, the `market-room-create` editor bridge command imports materials, creates the visual prefab and separate physical shell, retains the two corner cover anchors, bakes a separate navigation asset, and validates clearance before saving. `market-room-complete` can finish validation after a partially completed authoring operation; inspect the failure before using it. `market-room-validate` and `market-room-capture` provide subsequent checks and HDRP views.

The generated report records mesh counts and removed cladding count. Runtime AI, enemy count and patrol routes are not changed by this authoring operation.

`market-room-window` upgrades the existing three-door blockout to this window revision, retaining the previous gameplay fingerprint in GameplayThroughRoom.sha256.txt. It adds only the window breast-wall/sill colliders, updates owned navigation and saves after validation. The model's material remaps are preserved by the existing FBX metadata.

Beveled geometry provides the structural depth; subdued normal/detail maps supply coating grain and scuff relief. There is no POM or displacement. Shared materials and the floor are not modified. Source topology remains 8184 triangles, now in ten material groups. Visual-only refresh verifies the unchanged gameplay fingerprint and protected art files without running combat routes or rebaking navigation.

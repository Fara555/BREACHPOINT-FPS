# Market exterior facade

Focused external wall refinement requested after the interior lining/door work. The accessible east elevation and two end portals receive a coherent manufactured skin: broad enamel sheets, darker impact belt and upper service casing, folded corners/skirting/head closures, a fitted sign plaque and window maintenance faces. The west backing remains against the existing room boundary. No floor, roof slab, interior, furniture, shutter/sill, sign text, light, collider or gameplay object is changed.

Editable source: MarketFacade.blend, generated by build_facade.py. World-aligned real scale, 20796 triangles in four merged material groups, physical meter-space UV0 and UV1. Unity asset folder: Assets/Project/Art/Environment/ServiceQuarter/MarketFacade. One PF_MarketFacade instance lives beneath root20. The four owned HDRP materials intentionally reuse the accepted MarketWallLining PBR map library without modifying it; the enamel tint is mildly warm and smoothness capped to reduce scratch/highlight noise. Existing sRGB base maps, linear mask/normal data, mips, trilinear/aniso8 and geometric specular AA are retained. Depth comes from actual radiused/folded geometry and fine surface normals; no displacement/POM or new render settings.

No canonical room assets are rewritten and no old exterior faces are deleted. The thin new skin covers old unfinished backing/seams; visible planes have deliberate depth offsets (bed, fields, corner folds) rather than coplanar overlays. Panel depths project by roughly 8-22cm from the original wall backing, within existing facade/window framing. Both 2.8m end openings and the serving window stay clear. A second visual pass continues the dark breast wall between hatches and adjacent sheets, extends corner returns to cover exposed backing strips and keeps end head fields in the upper band color.

Editor bridge commands: market-facade-create / market-facade-validate / market-facade-capture. Create imports/remaps the model, makes the owned materials and prefab, saves the main scene and captures six actual HDRP views. First-run scene and before views are archived in Logs/MarketFacade. GameplayBefore.sha256.txt and ProtectedArtBefore.sha256.txt are persistent source baselines; validation checks exact current gameplay/collision/nav and all canonical room, interior-lining and standalone-prop file bytes. Door/window vertex-envelope checks, prefab/material/map references and previous recessed-door/prop checks also pass. No combat-route scenario, nav bake or runtime/Windows-build/GPU benchmark is run for this visual-only change. No manual setup, package or project setting is needed.
